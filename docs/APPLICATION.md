# Project description for applications

## Short version

Directed an AI-assisted research project that contributed a 10-input sorting network to Bert Dobbelaere's SorterHunter collection, reducing worst-case swaps from 21 to 20 with 29 comparators and 8 layers unchanged. Published exhaustive verification over all 3,628,800 input permutations, alongside median-selection and average-swap contributions with dated upstream attribution.

## Technical version

Established and directed an AI-assisted project in median-selection and sorting-network swap optimization. The public collection incorporated 84 network versions across 70 distinct targets in October 2026; 14 median versions improve earlier submissions. Led submission, with historical search and checker implementation by Claude agents and additional checking by ChatGPT. The maintainer also credits a proposed three-valued refinement for exact average-swap counting. The portfolio includes all contributed network sequences, deterministic output regression checks, and exhaustive 10-input worst-case verification. Large-input average values remain upstream-reported rather than independently reproduced here.

## Claims to avoid

- New general sorting-network size/depth records or global optimality.
- 84 distinct records, or 70 independently certified improvements: these are contribution counts; the 31-input average gain is unresolved against its old sampled baseline.
- Execution-time speedups inferred from swap percentages.
- Sole authorship of AI-generated search and verification implementations.
- Independent reproduction of the 63-input exact average.
